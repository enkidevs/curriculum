# What's Ahead

---
## Content

Here's some of what's coming up in LLM Fundamentals, the first part of this course:

- **How LLMs Work.** What a model does when it writes a reply, and where that can go wrong.
- **Calling A Model.** What your code sends to a model, and what comes back.
- **Tool Calling.** How a model can ask your code to fetch data or take an action.

After those, you'll learn how to get replies your code can check and how to choose the right model.
