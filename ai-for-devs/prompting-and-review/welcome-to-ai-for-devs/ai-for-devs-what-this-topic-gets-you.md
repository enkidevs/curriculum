# What You'll Learn

---
## Content

**This course teaches you to use AI assistants to get development work done faster, while you stay responsible for what ships.**

First, you'll learn to:

- turn a two-line ticket into a request the assistant can act on
- give the assistant the files and rules it needs to get the answer right
- check the code it writes against what you actually need

After that, you'll use the same habits for coding, debugging, documentation, and team communication.

> 💡 By the end, you'll know which tasks to hand to AI, how to ask for them, and how to check the result before you ship it.
