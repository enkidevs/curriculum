# Repurposing, Not Duplicating

---
## Content

Duplicating a piece makes it shorter or longer. Repurposing rebuilds it for a new channel.

Start by writing one sentence that says what the approved source actually claims. Then rebuild around each channel's job:

- caption: one useful point and an invitation
- email: context, supporting detail, and a next step
- script: scenes, spoken points, and what appears on screen

Here's the rule for all three:

```plain-text
Keep the source claim unchanged. Select and reorder only the material each version needs. Do not add facts that are absent from the source.
```

**If every version keeps the same opening, order, and paragraphs, it has been resized rather than repurposed.**

> ‼️ Check each version for facts the source never had, like "trusted by 500 companies".
