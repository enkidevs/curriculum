# What ChatGPT Adds Before You Type

---
## Content

ChatGPT can start with more than the prompt you are about to type.

- **Custom instructions** give it guidance you want in every chat.
- **Memory** can carry useful context from past chats, files, and connected apps when enabled.
- **Plugins** can package reusable instructions and connected tools for a repeated workflow.[1]

**So a new chat isn't always a blank slate.**

For a one-off chat that shouldn't use or create memory, start a **Temporary Chat** where available.[2]

Custom instructions and memory shape all your chats. A plugin sets up one kind of work you repeat.

> 💡 If an old assumption keeps showing up in new chats, check memory and custom instructions first.
