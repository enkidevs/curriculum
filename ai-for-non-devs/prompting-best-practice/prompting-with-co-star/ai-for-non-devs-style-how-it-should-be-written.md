# Style: How It Should Be Written

---
## Content

**S is for Style.** Ask yourself: how should the writing be built?

Style covers features such as sentence length, vocabulary, formality, and headings.

Compare:

**🚫 Vague**

```plain-text
Write the update in a professional style.
```

**✅ Specific**

```plain-text
Write the update the way our internal wiki reads: short sentences, no adjectives, a heading every few lines, no introduction.
```

"Professional" can mean many things. **The second prompt gives AI visible features to follow and gives you something concrete to check.**

> 💡 If you can't point to it in the text, it isn't a style instruction yet.
