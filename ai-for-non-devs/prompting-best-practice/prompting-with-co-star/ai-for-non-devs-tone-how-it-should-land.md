# Tone: How It Should Land

---
## Content

**T is for Tone.** Ask yourself: how should this message feel to the person reading it?

Style and tone are different. **The same short, plain style can carry two very different tones.**

Compare:

**Firm**

```plain-text
Write a short notice about the shift change. Use plain, short sentences. Make it firm and final, without an apology or invitation to negotiate.
```

**Apologetic**

```plain-text
Write a short notice about the shift change. Use plain, short sentences. Make it apologetic and acknowledge that this is the second change this quarter.
```

Both prompts use the same style. What changes is how the message lands.

If a draft is easy to scan but feels colder than you intended, change the tone.

> 💡 Style is how the sentences are built. Tone is what they make the person feel.
